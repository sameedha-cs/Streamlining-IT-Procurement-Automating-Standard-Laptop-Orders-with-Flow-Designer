Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

Project Overview
Streamlining IT Procurement is a documentation-based project that focuses on improving the IT procurement process through a structured software development approach. The repository is organized into phase-wise folders, making it easy to track the complete project lifecycle from idea generation to final demonstration.

Repository Structure
1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Planning
4. Project Design
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

Project Objective
- Organize IT procurement activities efficiently.
- Maintain clear project documentation.
- Follow a structured development process.
- Keep all project artifacts in a single repository.
